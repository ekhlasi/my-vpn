# اسکنر آی‌پی تمیز خصوصی (فقط سرورهای خودم)

- هیچ درخواستی به گیت‌هاب یا هیچ منبع خارجی زده نمی‌شود.
- فقط پنج فایل داخل `proxy/` خوانده می‌شوند: `de.txt`, `tr.txt`, `ru.txt`, `az.txt`, `uae.txt`.
- همه‌ی این فایل‌ها فقط باید شامل سرورهایی باشند که خودتان اجاره/خریداری کرده‌اید — هیچ آی‌پی
  اسکرپ‌شده یا متعلق به شخص دیگری اضافه نشده و نباید اضافه شود.

## محتوا

- `proxy/de.txt` → سرور آلمان (Hetzner): `socks4://94.130.105.94:80`
- `proxy/tr.txt` → سرور ترکیه: `socks4://89.187.155.67:80` و `socks4://89.187.155.67:8080`
- `proxy/ru.txt`، `proxy/az.txt`، `proxy/uae.txt` → فعلاً **خالی**. جای‌گذاری‌شده برای روسیه،
  آذربایجان و امارات تا هر وقت سروری در آن کشورها اجاره کردید، فقط یک خط
  `socks4://ip:port` داخلشان اضافه کنید — نیازی به تغییر کد یا رابط کاربری نیست،
  دراپ‌داون از قبل برای این سه کشور آماده است.

## اجرا

```bash
cd clean-ip-scanner
python3 server.py
```

سپس مرورگر را باز کنید: `http://127.0.0.1:8000/`

از پنل می‌توانید «آلمان»، «ترکیه» یا «هر دو» را انتخاب کرده و روی «شروع اسکن» بزنید.
اسکنر برای هر سرور یک هندشیک واقعی SOCKS4 انجام می‌دهد (بدون رد و بدل کردن داده‌ی
واقعی کاربر) و پینگ + وضعیت سالم/قطع بودن را نشان می‌دهد.

## دو حالت اسکن

- **SOCKS4** — هندشیک واقعی SOCKS4 روی همان پورتی که در `proxy/*.txt` نوشته‌اید (۸۰ یا ۸۰۸۰). فقط سلامت پروکسی خودتان را می‌سنجد.
- **IP تمیز (SNI/TLS)** — دقیقاً همان مکانیزم اسکنر پروژه ۲: یک هندشیک TLS با SNI مشخص روی پورت‌های `443, 2053, 2083, 2087, 2096, 8443` (همان پورت‌های TLS کلادفلر). دامنه/SNI به‌صورت خودکار از اکانت کلادفلر شما تشخیص داده می‌شود:
  1. یک بار توکن Cloudflare API را داخل برنامه وارد کنید (فقط یک‌بار، در `config.local.json` ذخیره می‌شود — این فایل هرگز نباید commit شود، در `.gitignore` هم هست).
  2. برنامه با همان روش خودِ پنل (`src/services/cf-accounts.ts`) توکن را verify می‌کند، Account ID و ساب‌دامین ورکرها را می‌گیرد و آن را با نام ورکر داخل `wrangler.toml` ترکیب می‌کند تا دامنه نهایی ساخته شود — نیازی به تایپ دستی دامنه نیست.
  3. اگر نخواستید توکن بدهید، می‌توانید دامنه را یک‌بار دستی هم وارد کنید.

## اضافه کردن سرور جدید خودتان

اگر بعداً سرور دیگری (باز هم فقط متعلق به خودتان) اجاره کردید، کافی است یک خط جدید
به همان فایل کشور مربوطه اضافه کنید (یا فایل کشور جدیدی مثل `ae.txt` بسازید) —
نیازی به تغییر کد نیست.
