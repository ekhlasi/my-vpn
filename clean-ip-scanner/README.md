# اسکنر آی‌پی تمیز — دو مرحله‌ای (کشف از پروکسی، اعتبارسنجی از نتِ خودتان)

**این جهت عمدی است و نباید برعکس شود:**

1. **کشف (از طریق پروکسی):** یکی از پروکسی‌های SOCKS4 شما (فایل‌های
   `proxy/de.txt`, `proxy/tr.txt`, `proxy/ru.txt`, `proxy/az.txt`,
   `proxy/uae.txt`) برای تونل‌کردن یک کوئری DoH (نوع A) به سمت دامنه/SNI
   پنل یا ورکر شما استفاده می‌شود. چون این کوئری از داخل شبکه‌ی کشور آن
   پروکسی خارج می‌شود، جوابی که کلادفلر برمی‌گرداند مخصوص همان مسیر شبکه
   است — این آی‌پی‌ها فقط **کاندید** هستند.
2. **اعتبارسنجی (از نتِ خودتان):** همان کاندیدها با یک هندشیک TLS/SNI
   واقعی، **مستقیم و بدون هیچ پروکسی‌ای**، از روی همان دستگاهی که
   `server.py` را اجرا می‌کنید تست می‌شوند (۳ بار، میانگین پینگ). این
   دقیقاً همان چیزی است که در استفاده‌ی واقعی اتفاق می‌افتد، پس اعتبارسنجی
   نهایی همیشه باید از نتِ خودتان باشد، نه از پروکسی.

## بخش‌های پنل

- **دریافت آی‌پی از مخزن محلی** — از `ips.txt` (کپی محلی از لیست پروژه ۲،
  بدون دانلود خارجی) بر اساس اپراتور.
- **ورود دستی آی‌پی** — آی‌پی تکی یا CIDR.
- **کشف از طریق پروکسی‌های خودم** (بخش جدید) — دقیقاً مرحله‌ی ۱ بالا؛
  کشور پروکسی را انتخاب کنید، دکمه‌ی «شروع کشف» را بزنید، نتیجه به‌عنوان
  لیست کاندید در جدول لود می‌شود.

در هر سه حالت، دکمه‌ی «شروع اسکن SNI» همان مرحله‌ی ۲ (اعتبارسنجی از نتِ
خودتان) را روی لیست فعلی اجرا می‌کند.

## یک نکته مهم درباره‌ی فایل‌های proxy/*.txt

این فایل‌ها فعلاً عمدتاً لیست‌های بزرگ پروکسی عمومی/جمع‌آوری‌شده هستند
(SOCKS5، HTTP و SOCKS4 با هم، هزاران خط) نه لزوماً سرورهایی که خودتان
اجاره کرده‌اید. بخش «کشف» فقط از خطوط `socks4://` استفاده می‌کند (چون
تونل‌زنی اینجا فقط SOCKS4 را پیاده می‌کند)، حداکثر ۲۵ مورد از هر کشور در
هر اجرا امتحان می‌شود تا کند نشود. اگر می‌خواهید فقط پروکسی‌های واقعاً
خودتان استفاده شوند، محتوای این فایل‌ها را با پروکسی‌های خودتان جایگزین
کنید.

## اجرا

```bash
cd clean-ip-scanner
python3 server.py
```

سپس مرورگر را باز کنید: `http://127.0.0.1:8000/`

دامنه/SNI پنل یا ورکر خودتان را بالا وارد کنید، یک منبع آی‌پی (مخزن محلی،
دستی، یا کشف از پروکسی) انتخاب کنید، و روی «شروع اسکن SNI» بزنید.
